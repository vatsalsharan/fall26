What are things you found interesting about the papers for this class?

I found the paper's main premise in general interesting actually because it's pretty connected to something I've been wondering about, which is if models respond differently when a user's identity is directly stated vs inferred from things like their writing style or dialect. This paper uses explicit and implicit in a different sense, but I found it interesting that a model can reject stereotypes when asked directly but still make biased recommendations. I'm curious as to how the way a model learns someone's identity could affect this.

What questions do you have about the papers for this class? What do you hope to learn from the discussion?

Would we see different patterns of bias if someone directly stated their identity vs the model inferring it from indirect cues? I also wonder if those two cases involve similar representations inside the model, and how we could test whether those representations actually affect its responses. I hope to learn what these behavioral tests can tell us about where the bias comes from.
