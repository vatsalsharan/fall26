What are things you found interesting about the papers for this class?

It's interesting to see that Fairness team often involved only when the model in deployment, but did not participate from the start of design. What questions do you have about the papers for this class? What do you hope to learn from the discussion?

How do we design a systematic metric to allow every fairness team in different project can use it without need to design new-specific metric? With this systematic metric, different project can reuse these things and save a lot of time.
