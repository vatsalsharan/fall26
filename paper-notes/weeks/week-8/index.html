What are things you found interesting about the papers for this class?

Fairness through Difference Awareness: I was surprised that prompts telling models to be unbiased often made the difference awareness worse. I'm curious about how it's actually represented internally in the model that might be causing this? Uncertainty Quantification in LLM Agents: I found it interesting that uncertainty can mean there are multiple good options and the agent doesn't know which to choose, or it can also mean a lack of knowledge. I initially had just thought of uncertainty as lacking knowledge. Another thing I noticed is that maybe if the agent asks the user too many questions, maybe this could improve the reliability, but it also worsens the user experience (the user may start to get frustrated or annoyed). I'm curious how we can analyze this tradeoff.

What questions do you have about the papers for this class? What do you hope to learn from the discussion?

Fairness through Difference Awareness: I'm curious about what actually happens internally when the model is told to be unbiased. Does it still recognize relevant differences but avoid expressing them, or is something else happening? Also, how can we ensure that models are aware of social stereotypes enough to recognize and challenge them and make context-aware decisions while avoiding using those stereotypes to make harmful decisions? Uncertainty Quantification in LLM Agents: How can we distinguish uncertainty in the case of multiple valid choices vs missing information? How should an agent decide when to ask the user, check a tool, or just proceed (especially when different mistakes might have different consequences)?
